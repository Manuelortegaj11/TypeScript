# 01 · Por qué usar TypeScript

> **Sección:** Introducción a TypeScript · **Duración:** 07:25 min

## Notas

### Qué es TypeScript

TypeScript es un superset de JavaScript creado por Microsoft: todo código JavaScript válido también es TypeScript, y encima le agrega un sistema de tipos.

### Por qué usarlo

- **Previene errores:** según un estudio [1], TypeScript puede detectar alrededor del 15 % de los bugs de un proyecto JavaScript antes de que lleguen a producción.
- **Feedback inmediato:** los errores aparecen en el editor mientras escribo, no cuando ejecuto el programa.
- **Mejor experiencia en el editor:** autocompletado, documentación al pasar el mouse y cambios más seguros en el código.

### Cambio de mentalidad

El tipado analiza mi código constantemente: a la misma velocidad a la que escribo, me indica si hay un error o si algo se puede escribir de una mejor manera.

### Referencia

[1] Zheng Gao, Christian Bird y Earl T. Barr, *To Type or Not to Type: Quantifying Detectable Bugs in JavaScript* (ICSE 2017).
